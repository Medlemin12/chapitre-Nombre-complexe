Cours : les nombres complexes

1. Définition et forme algébrique

On introduit le nombre i tel que i² = −1. Tout nombre complexe s’écrit z = a + ib avec a, b réels. a est la partie réelle Re(z), b la partie imaginaire Im(z).

Puissances de i : i⁰=1, i¹=i, i²=−1, i³=−i, puis le cycle se répète (période 4).

Exemple : i²⁰²⁶ = i² = −1 car 2026 = 4×506 + 2.

2. Opérations

On calcule comme avec des réels, en remplaçant i² par −1.

(a+ib)+(c+id) = (a+c)+i(b+d)
(a+ib)(c+id) = (ac−bd)+i(ad+bc)

Exemple : (2+i)² = 4+4i+i² = 3+4i.

Pour un quotient, on multiplie par le conjugué du dénominateur : 1/(1+i) = (1−i)/2.

3. Conjugué et module

Le conjugué de z = a+ib est z̄ = a−ib. Le module est |z| = √(a²+b²).

z·z̄ = a²+b² = |z|²
z + z̄ = 2a ; z − z̄ = 2ib

z est réel ⇔ z = z̄. z est imaginaire pur ⇔ z = −z̄.

Exemple : |3+4i| = √(9+16) = 5.

4. Forme trigonométrique et exponentielle

Pour z ≠ 0, avec r = |z| et θ = arg(z) :

z = r(cos θ + i sin θ) = r·eiθ

On trouve θ grâce à cos θ = a/r et sin θ = b/r.

Exemple : 1+i = √2(cos π/4 + i sin π/4) = √2·eiπ/4.

arg(z₁z₂) = arg z₁ + arg z₂
arg(z₁/z₂) = arg z₁ − arg z₂
arg(zⁿ) = n·arg z

Formule de Moivre : (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ.

5. Équation du second degré

Pour az²+bz+c = 0 avec a, b, c réels, on calcule Δ = b²−4ac.

Δ > 0 : deux racines réelles
Δ = 0 : une racine double
Δ < 0 : z = (−b ± i√(−Δ)) / 2a (racines conjuguées)

Exemple : z²−2z+5 = 0 → Δ = −16 → z = 1 ± 2i.

6. Géométrie dans le plan complexe

Le point M(a ; b) a pour affixe z = a+ib.

Vecteur AB : zB − zA
Distance AB = |zB − zA|
Milieu de [AB] : (zA + zB)/2
7. Identités à retenir
(a+ib)² = a² − b² + 2iab
(a−ib)² = a² − b² − 2iab
(a+ib)(a−ib) = a² + b²

La dernière identité donne un nombre réel : c’est z·z̄ = |z|².

8. Racines carrées d’un nombre complexe

On cherche w = x + iy tel que w² = z = a + ib. On écrit le système :

x² − y² = a
2xy = b
x² + y² = √(a²+b²) (égalité des modules)

En additionnant et en soustrayant : x² = (√(a²+b²)+a)/2 et y² = (√(a²+b²)−a)/2. Le signe de xy est celui de b.

Exemple : z = 3+4i, |z| = 5 → x² = 4, y² = 1, 2xy = 4 > 0 → w = ±(2+i).

Vérification : (2+i)² = 4+4i−1 = 3+4i.

Autre exemple : z = −5+12i, |z| = 13 → x² = 4, y² = 9 → w = ±(2+3i).
